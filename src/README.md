# src/

Scripts that build and simulate the cortical column. 

| File | Content |
| --- | --- |
| `column.py` | builds the full cortical column by assembling all the layers |
| `layer.py` | builds one cortical layer (with E / PV / SOM / VIP populations) |
| `network.py` | builds a network of multiple connected columns (unused so far)|
| `analysis.py` | utility scripts that compute the LFP, firing rates, etc |
| `visualization.py` | plotting helpers (rasters, rates, power spectrum) |
| `cleo_plots.py` | plotting helpers for the [Cleo](https://github.com/siplab-gt/cleo) electrophysiology sims |
